# Clip & Clic - Copilot Instructions

## Project Overview

This is a Vue.js + TypeScript application for an e-commerce platform specializing in:
- **School Items**: Supplies, materials, and educational products
- **Technology Hardware**: Keyboards, mice, webcams, and other tech accessories

## Core Development Guidelines

### 1. Text & Localization
- **CRITICAL**: All user-facing text must be written in Spanish in `src/infrastructure/lang/spanish.ts`
- English translations should also be added to `src/infrastructure/lang/english.ts`
- Never hardcode text directly in components
- Use the `appTexts` object from the language files: `import { appTexts } from '@/infrastructure/lang/spanish'`

### 2. Testing
- **Do NOT run unit tests** - there are currently no unit tests in this project
- Do not create test files unless specifically requested

### 3. Styling & Layout
- **Always use Bootstrap 5** for layout and styling
- Bootstrap classes are available globally
- For custom styling, use scoped `<style scoped>` blocks in Vue components
- **DO NOT add background colors to view components** - Keep views transparent to allow the global page background to show through
- Follow the existing color scheme (see Design System section below)

### 4. Icons
- **FontAwesome 6.7 is pre-installed and available**
- Icons are already imported in `src/fontawesome-icons.ts`
- Use `<i class="fa-[style] fa-[icon-name]"></i>` or the FontAwesome component if available

## Application Flow

### 1. Home Page (`/`)
- **Location**: `src/views/HomeView.vue`
- **Purpose**: Display deals and special offers
- **Components**: Hero section, featured products carousel, promotional banners
- **Features**:
  - Show current deals on school and technology items
  - Call-to-action sections
  - Quick access to product categories

### 2. Products Listing Page
- **Route Pattern**: `/products` or `/[category]` or `/[category]/[subcategory]`
- **Examples**:
  - `/products` - show all products
  - `/school` - show all school items
  - `/technology/audio` - show technology products in audio category
  - `/technology/peripheral` - show peripherals like keyboards and mice
- **Functionality**:
  - Filter products based on URL route
  - Display products in a grid/card layout
  - Show product name, image, price, and quick actions
  - Implement pagination or infinite scroll if needed
  - Include filtering/sorting options

### 3. Product Detail Page
- **Route Pattern**: `/product/:productId`
- **Example**: `/product/2245`
- **Functionality**:
  - Display full product information
  - Product images (gallery view if multiple images)
  - Detailed description and specifications
  - Price and availability status
  - Quantity selector
  - Add to cart button
  - Related products recommendation

## Design System

### Color Palette & Management
**All colors are centrally managed for easy updates:**

- **Primary Background**: `#FBCEB1` (Warm peach)
- **Bisque/Accent**: `#ffe4c4` (Light peach)
- **Bisque Light**: `#f0d4e8` (Light pink)
- **Text Color**: `#972805` (Dark brown-red)
- **Navbar Background**: `#732626` (Deep brown-red)

**To change colors:**
1. Update the `COLORS` constant in `src/infrastructure/constants/constants.ts`
2. The CSS variables in `src/assets/main.css` (`:root` section) automatically reference these values
3. Colors are used as CSS variables throughout the app (e.g., `var(--color-primary)`, `var(--color-bisque)`)

**Example:**
```typescript
// src/infrastructure/constants/constants.ts
export const COLORS = {
  PRIMARY: '#FBCEB1',        // Main background
  BISQUE: '#ffe4c4',         // Accent color
  BISQUE_LIGHT: '#f0d4e8',   // Light variant
} as const;
```

CSS variables are then available globally:
```css
/* src/assets/main.css */
:root {
  --color-primary: #FBCEB1;
  --color-bisque: #ffe4c4;
  --color-bisque-light: #f0d4e8;
}
```

## Best Practices

1. **Component Organization**: Keep components focused and single-responsibility
2. **Composition API**: Use `<script setup>` syntax for new components
3. **Types**: Define interfaces/types for all data structures
4. **Performance**: Use `lazy` loading for images, optimize imports
5. **Accessibility**: Include proper ARIA labels and semantic HTML
6. **Dark Theme**: Maintain consistency with existing dark theme throughout
7. **Responsive**: Test on mobile, tablet, and desktop viewports
